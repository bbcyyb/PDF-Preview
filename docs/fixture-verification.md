# Fixture Verification Notes

The sample fixture pair is generated by `scripts/generate-fixtures.mjs`.

- PDF fixture: `public/fixtures/sample-document.pdf`
- OCR fixture: `public/fixtures/sample-document.ocr.json`
- Source document aid: `fixtures/source/sample-document.zh.md`

The OCR coordinates use a top-left origin, pixel units, 1-based page numbers, and the same 595 x 842 source dimensions as the generated PDF page. The generator draws a rectangle around each PDF value from the same deterministic field source used to emit the OCR `bbox`, so fixture alignment should remain exact within PDF.js canvas scaling tolerance.

Automated verification currently covers:

- Every OCR field references an existing page.
- Every mappable field has valid bbox and source dimensions.
- OCR JSON remains equal to the committed deterministic fixture source.
- Highlight overlay scaling matches expected fixture coordinates.
- `npm run fixtures:check` confirms generated fixture files are stable.

Manual browser verification is still needed for final visual confirmation of PDF.js rendering and smooth scrolling behavior in the running app.
